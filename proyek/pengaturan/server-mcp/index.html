Konfigurasi Akses

Tentukan apa saja yang boleh dilakukan AI luar di workspace proyek ini. Perubahan tersimpan otomatis.

Lihat & baca file

AI bisa melihat daftar file dan membaca isinya

Tulis & ubah file

AI bisa membuat file baru dan mengubah isi file

Hapus file

AI bisa menghapus file atau folder di workspace

Chat AI Clincoo

AI bisa minta bantuan AI Clincoo: kompilasi, refactor, tanya konteks proyek (gak makan kuota chat kamu)

Deployment

AI bisa mempublikasikan situs proyek dan melihat status deployment

Pengaturan & Integrasi

AI bisa membaca dan mengubah pengaturan proyek (nama app, deskripsi, webhook)

Kirim Email

AI bisa mengirim email lewat email API proyek (mengikuti kuota bulanan proyek)

Notifikasi

AI bisa membaca dan mengirim notifikasi ke dashboard Clincoo kamu

URL + Token

Untuk aplikasi yang cuma sediain kolom nama + URL server (tanpa kolom token). Token udah nempel di URL, jadi gak perlu header Authorization.
