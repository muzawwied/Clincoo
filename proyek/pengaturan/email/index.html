Dokumentasi API

Satu endpoint untuk semua kebutuhan email situs deploy-mu.

POST https://app.clincoo.buzz/api/email
Content-Type: application/json

{ "action": "send",
  "api_key": "clc_email_••••••••••••",
  "to": "pelanggan@contoh.com",
  "subject": "Pesanan diterima",
  "html": "<h1>Terima kasih!</h1><p>Pesananmu sedang diproses.</p>",
  "reply_to": "kamu@domainmu.com" }

api_key — API key proyek (bisa juga dikirim via header Authorization: Bearer).

to — alamat tujuan.

subject — subjek email.

html — isi email dalam HTML.

reply_to — opsional, alamat balasan pelanggan.

Penggunaan Clincoo Email API tunduk pada Syarat & Ketentuan dan Kebijakan Privasi Clincoo.
