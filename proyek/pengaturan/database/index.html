Belum ada tabel

Buat tabel pertamamu lewat tombol di atas untuk mulai menyimpan data aplikasi.

Cara pemakaian

1

Buat tabel. Klik Buat tabel di atas, beri nama, lalu tentukan kolomnya — misal tabel pengguna dengan kolom nama dan email.

2

Isi data. Buka tabelnya, lalu tambah, ubah, atau hapus baris kapan saja — datanya langsung tersimpan.

3

Buat kunci akses. Di bagian Akses dari aplikasi di bawah, buat kuncinya dan simpan di tempat aman.

4

Sambungkan aplikasimu. Tempel kunci sebagai Bearer token di kode aplikasi — contoh pemakaian lengkap tersedia tepat di bawah kuncinya.

Akses dari aplikasi

Sambungkan aplikasi deploy-mu ke database proyek lewat kunci API sebagai Bearer token.

Memuat…

Belum ada kunci akses untuk proyek ini. Kunci API dipakai aplikasi yang kamu deploy untuk mengakses database — dikirim sebagai Bearer token di header Authorization pada setiap request. Buat kuncinya di sini, simpan di tempat aman, lalu tempel ke kode aplikasimu. Kunci bisa diganti kapan saja; kunci lama otomatis berhenti berlaku begitu diganti.
