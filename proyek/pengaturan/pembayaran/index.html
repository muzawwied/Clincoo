Kunci Publik Pembayaran

Dipakai situs deploy-mu untuk membuat QR bayar via /api/pay

Dokumentasi API
Contoh pemakaian dari situs deploy

1. Buat transaksi QR — respons berisi checkout_url, qr_image (gambar QR siap embed), dan qr_string:

curl -X POST https://app.clincoo.buzz/api/pay \
  -H "Content-Type: application/json" \
  -d '{"action":"create","key":"clc_pk_…","amount":50000,"description":"Paket Premium"}'

2. Cek status pembayaran dari situs deploy-mu (berubah jadi paid setelah dibayar):

curl "https://app.clincoo.buzz/api/pay?action=status&key=clc_pk_…&order_id=clincoo…"

Nominal Rp 1.000 – Rp 100.000.000. Biaya QRIS 3,8% ditanggung pembeli. Dana masuk ke saldo proyekmu.
