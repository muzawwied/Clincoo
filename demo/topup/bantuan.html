Ada yang bisa kami bantu?

Panduan top up

  1. Buka halaman Top Up dan pilih game favoritmu.
  2. Pilih nominal item — harga yang tampil adalah harga final.
  3. Masukkan User ID (dan Server ID bila game mewajibkan).
  4. Pilih metode pembayaran dan selesaikan pembayaran.
  5. Item masuk otomatis — cek halaman Status bila ingin memantau.

Pertanyaan yang sering diajukan

Rata-rata kurang dari 30 detik setelah pembayaran terverifikasi. Pada jam sibuk atau saat server game mengalami gangguan, maksimal 24 jam.

Penyebab paling umum: ID akun salah, nickname tidak cocok, atau server game sedang maintenance. Dana otomatis dikembalikan penuh ke metode pembayaran asal dalam 1×24 jam.

Selama pesanan belum diproses, hubungi CS lewat halaman Kontak dengan kode pesanan. Jika item sudah terkirim, sayangnya tidak bisa ditarik kembali — pastikan ID benar sebelum membayar.

QRIS, GoPay, OVO, DANA, ShopeePay, BCA & BRI Virtual Account, dan pembayaran tunai di Alfamart / Indomaret.

Kami hanya meminta data minimum untuk pengiriman item (User ID / Server ID). Kami tidak pernah meminta password, OTP, atau kode verifikasi. Data dienkripsi dan tidak dibagikan ke pihak ketiga.

Refund penuh otomatis jika pesanan gagal atau item tidak masuk dalam 24 jam. Refund tidak berlaku jika ID yang diberikan valid dan item sudah terkirim.

Sistem top up bekerja otomatis 24/7. Tim CS hadir setiap hari 24 jam dengan waktu respons rata-rata di bawah 15 menit.

Masukkan kode pesanan (contoh VY-XXXXXXX) di halaman Cek Pesanan. Kode juga tersimpan di riwayat perangkatmu.

Syarat & ketentuan

Dengan menggunakan Vylonium, kamu menyatakan bahwa: (1) data akun yang diberikan akurat dan milikmu sendiri atau dengan izin pemiliknya, (2) kamu bertanggung jawab atas kesalahan input data yang menyebabkan item terkirim ke akun lain, (3) semua harga dapat berubah sewaktu-waktu mengikuti kebijakan distributor resmi.

Kebijakan privasi: kami menyimpan data transaksi secara terenkripsi, tidak menjual maupun membagikan data pribadi ke pihak ketiga, dan hanya memproses data sebatas yang diperlukan untuk pengiriman item.
